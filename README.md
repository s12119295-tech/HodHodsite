# هدهد

پیام‌رسان ساده با ثبت‌نام با شماره موبایل، ساخت روم، لینک دعوت عمومی، و ارسال متن، صدا (ویس)، تصویر، ویدیو و آهنگ. ساخته‌شده با React + Vite + Supabase.

## ۱) ساخت پروژه در Supabase

۱. در [supabase.com](https://supabase.com) یک پروژه بساز.
۲. برو به **SQL Editor** و کل محتوای فایل `supabase/schema.sql` را اجرا کن (جدول‌ها، امنیت ردیفی RLS، باکت مدیا و realtime را می‌سازد).
۳. برو به **Authentication > Providers > Phone** و آن را فعال کن. برای ارسال واقعی پیامک باید یک سرویس‌دهنده SMS (مثلاً Twilio یا MSG91) در همان صفحه وصل کنی — بدون آن کد تایید ارسال نمی‌شود.
   - نکته: اگر سرویس پیامک ایرانی نداری، در همان بخش می‌توانی «Test phone numbers» برای تست تعریف کنی تا بدون هزینه امتحان کنی.
۴. از **Project Settings > API** مقدار `Project URL` و `anon public key` را بردار.

## ۲) اجرای پروژه روی موبایل/کامپیوتر

```bash
npm install
cp .env.example .env
# مقادیر VITE_SUPABASE_URL و VITE_SUPABASE_ANON_KEY را در .env بگذار
npm run dev
```

اگر از گوشی با Termux یا از یک ابزار وب‌محور کار می‌کنی، می‌توانی مستقیم فایل‌ها را در GitHub ویرایش/آپلود کنی (مرحله بعد) و از GitHub Actions برای build و انتشار استفاده کنی — نیازی به اجرای لوکال نیست.

## ۳) بالا بردن روی گیت‌هاب از موبایل

۱. یک ریپوی جدید در GitHub بساز (مثلاً `hodhod`).
۲. در اپ GitHub یا مرورگر موبایل، همه‌ی فایل‌های این پوشه را آپلود کن (گزینه «Add file > Upload files» در صفحه ریپو، می‌توانی چند فایل/پوشه را همزمان بکشی).
۳. در ریپو برو به **Settings > Secrets and variables > Actions** و دو مقدار زیر را اضافه کن:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
۴. برو به **Settings > Pages** و در بخش Source گزینه **GitHub Actions** را انتخاب کن.
۵. هر بار که به شاخه `main` پوش کنی، وورک‌فلوی `.github/workflows/deploy.yml` به‌صورت خودکار سایت را می‌سازد و روی GitHub Pages منتشر می‌کند. آدرس نهایی در تب Actions بعد از اتمام build نمایش داده می‌شود.

## ۴) استفاده از سایت

- ثبت‌نام: شماره موبایل، کد تایید پیامکی، اسم و نام کاربری.
- از صفحه روم‌ها: «روم جدید» بساز یا با «کد/لینک دعوت» به روم کسی دیگر بپیوند.
- داخل هر روم، دکمه کپی بالای صفحه لینک دعوت روم را کپی می‌کند (به‌شکل `.../#/join/<code>`) — همین لینک را با بقیه به اشتراک بگذار.
- برای پیام: متن بنویس و بفرست، یا با دکمه `+` عکس/ویدیو/آهنگ بفرست، یا دکمه میکروفون را بزن تا ویس ضبط شود (با زدن دوباره، ویس ارسال می‌شود).

## ساختار پروژه

```
src/
  lib/supabase.js      اتصال به Supabase
  hooks/useAuth.js      وضعیت ورود و پروفایل
  pages/Auth.jsx        ثبت‌نام/ورود با شماره
  pages/Rooms.jsx        لیست و ساخت روم
  pages/Room.jsx          چت زنده + رسانه
  pages/JoinLink.jsx      ورود خودکار با لینک دعوت
  components/Icons.jsx    آیکون‌های SVG (بدون ایموجی)
supabase/schema.sql        اسکیمای دیتابیس + RLS + باکت مدیا
```

## نکات

- تمام رسانه‌ها (عکس/ویدیو/آهنگ/ویس) در باکت عمومی `media` در Supabase Storage ذخیره می‌شوند.
- پیام‌ها به‌صورت زنده (Realtime) بین اعضای هر روم همگام می‌شوند.
- طراحی رابط کاربری بدون ایموجی و با آیکون‌های SVG اختصاصی انجام شده است.
